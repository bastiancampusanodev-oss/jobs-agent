# Autonomous Job Agent — proyecto técnico real

Bastián diseñó, desarrolló y opera un agente autónomo end-to-end
orientado a automatizar un workflow real.

## Stack y capacidades implementadas

- Python 3.12
- OpenAI API / LLM reasoning
- Pydantic structured outputs
- RAG con conocimiento local
- Playwright
- Brave mediante Chrome DevTools Protocol (CDP)
- browser automation
- formularios web dinámicos
- Trix editors
- selects dinámicos
- text / select / radio / checkbox
- state machine
- SQLite como estado persistente
- YAML para configuración y reglas
- deduplicación de entidades
- recuperación de drafts
- recuperación ante fallos y redirects
- guardrails
- auditoría previa a acciones irreversibles
- protección contra doble submit
- screenshots pre-submit
- logging
- systemd para operación autónoma continua
- discovery multi-categoría
- clasificación SKIP / REVIEW / APPLY

## Problemas de ingeniería resueltos

- destruction of execution context durante navegación Playwright
- recuperación automática después de redirects
- drafts y reanudación de workflows interrumpidos
- páginas de formulario variables
- preguntas CUSTOM dinámicas
- selección contextual de CV
- respuestas en español e inglés
- persistencia para evitar procesamiento repetido
- deduplicación entre URLs distintas de una misma entidad
- separación entre decisiones reversibles e irreversibles
- auditoría final antes de ejecutar submit
- tolerancia a errores sin detener todo el procesamiento

## Guardrails de veracidad

Nunca afirmar:

- despliegue empresarial a gran escala
- miles de usuarios
- plataforma SaaS comercial
- despliegue AWS/Azure/GCP si no existe
- métricas inventadas
- experiencia profesional pagada en Agentic AI si no corresponde

Sí afirmar:

- proyecto real y actualmente operativo
- workflow real end-to-end
- operación autónoma
- estado persistente
- recuperación ante fallos
- RAG
- structured outputs
- browser automation
- guardrails
- auditoría antes de acciones irreversibles
